# Implementation Plan: Fly-and-Detect E2E with Virtual Video Stream

**Branch**: `009-fly-detect-e2e` | **Date**: 2026-11-17 | **Spec**: [spec.md](file:///home/remi/Projects/Intent-Swarm-Commander/specs/009-fly-detect-e2e/spec.md)  
**Input**: Feature specification from `/specs/009-fly-detect-e2e/spec.md`

## Summary

Enable true end-to-end Fly-and-Detect missions across `isc_backend`, `isc_edge`, `drone_sim` (PX4 SITL `sihsim_quadx`), and a new `virtual_cam` HTTP MJPEG service in `docker-compose.yml`. Operators can feed any video via `VIRTUAL_VIDEO_PATH` (defaulting to a real COCO sample frame with `person`/`bus`), `CameraStream` reads the stream cleanly via `CAMERA_SOURCE`, `dispatch_edge_mission_activity` dispatches both `POST /navigate` and `POST /target` with command-driven `detection_mode` (`report_only` vs `intercept`), and a zero-mock Playwright test (`tests/e2e/prod_fly_detect.spec.js`) verifies PX4 flight displacement, YOLO-E detection, MinIO JPEG snapshot retrieval, and Memgraph target correlation in the dashboard.

## Phase 1 Design Highlights

1. **`virtual_cam` Service (`scripts/virtual_cam_server.py` + `docker-compose.yml`)**:
   - Serves `GET /stream` (`multipart/x-mixed-replace; boundary=frame`) and `GET /health` on port `8091`, with a Docker `healthcheck` on `GET /health` so `edge_drone` starts via `depends_on: { virtual_cam: { condition: service_healthy } }`.
   - Reads `VIRTUAL_VIDEO_PATH`: if `.mp4`/`.avi`/video, loops via `cv2.VideoCapture`; if image (`.jpg`/`.png`, defaulting to `ultralytics/assets/bus.jpg`), encodes JPEG frames at `FPS` (default `5` fps).
2. **`CameraStream` (`src/edge/vision/camera.py`)**:
   - Accepts `source: int | str | None = None`, defaulting from `CAMERA_SOURCE` env var (`"0"` -> `0`, URLs kept as `str`).
   - Loops/reopens gracefully on stream EOF if `isinstance(self.source, str)`? Better: `virtual_cam` already loops infinitely, and if `self._capture` is closed between missions, `FlightController.start()` calls `self.camera.open()` cleanly.
3. **Edge Decoupling & Detection Modes (`src/edge/api/server.py`, `src/edge/navigation/flight_controller.py`)**:
   - Separate `_nav_task` (`POST /navigate`) and `_vision_task` (`POST /target`).
   - Add `detection_mode: Literal["report_only", "intercept"] = "report_only"` to `TargetRequest` and `FlightController`.
   - Throttle `publish_detection` slightly (e.g. minimum `1.0s` interval per class) so `yolov8n.pt` CPU inference doesn't flood MQTT/MinIO with 10 identical crops per second, while still publishing immediately on first detection.
4. **Backend SMEAC Dispatch (`src/uservice/smeac/operations/process.py`)**:
   - In `dispatch_edge_mission_activity`, after dispatching `POST /navigate`, iterate `commands` and for each command with non-empty `target_object_class`, call `POST {endpoint_url}/target` with `{"target_object_class": ..., "command_id": ..., "detection_mode": "intercept" if mission_type == "strike" else "report_only"}`.
5. **Post-Design Constitution Check**: Passed — zero mocks in `src/`, single `VideoCapture` path, scripts confined to `scripts/`.
